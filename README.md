## 国内用户怎么付？四条路的成本和风险

这才是“ChatGPT Plus 一个月多少钱”这个问题里真正因人而异的部分。

**第一条路：外区 Apple ID + App Store 订阅。** 常见的是美区、日区、台区、新加坡区，价格就是上表标价。付款需要该区银行卡或该区礼品卡，大陆发行的卡绑不上外区账号；礼品卡从第三方买通常有溢价，这笔钱要算进总成本。风险有两层：来源不明的礼品卡一旦被判盗刷，余额冻结、整个 Apple ID 可能被锁；账号从大陆使用本身就落在 OpenAI “可能封号或停用”的条款里。好处是退款和取消都在 Apple 侧操作，不用求 OpenAI。

**第二条路：外币卡在网页端付款。** 网页端用 Stripe 收款，接受主流信用卡。大陆发行的双币卡有一部分能过，很多会在结账页看到 "Your card was declined"——拒绝你的是 Stripe 的风控，跟卡里有没有余额无关，银联单币卡基本走不通。能过的卡按美元入账，发卡行折算人民币后一般再收 1%–2% 的货币转换费，所以账单上通常比 135 元再多几元。

**第三条路：代充或拼车。** 代充是把账号交给卖家，或直接买一个付过费的账号。卖家的付款来源你看不见，常见的是盗刷卡和批量注册的促销账号，原持卡人一拒付，订阅被撤销、账号跟着遭殃。拼车是几个人合买 Business 席位，违反 OpenAI 条款，席位归工作区管理员所有，他随时能把你移出去，你的对话也留在他的工作区里。这两种方式都拿不到任何票据。
